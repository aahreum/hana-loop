# 과제 개요

## 과제 목적

HanaLoop 프론트엔드 개발자 채용 과제.  
기업의 탄소 배출량을 관리하고 시각화하는 웹 기반 대시보드 구현.

## 핵심 평가 기준 (비율)

| 항목 | 비율 | 핵심 포인트 |
|------|------|------------|
| 창의성과 문제 해결 사고 | 25% | 왜 이렇게 설계했는가 |
| UI/UX 디자인 및 미적 감각 | 25% | 현대적이고 직관적인 인터페이스 |
| UI 엔지니어링 | 20% | 상태 분리, 반응형, 에러/로딩 처리 |
| 소프트웨어 엔지니어링 | 20% | 모듈화, 성능 |
| 코드 품질 | 10% | 가독성, 타입 안정성, 테스트 |

## 도메인 핵심 흐름

```
활동 데이터 입력
→ 배출계수 조회
→ 탄소 배출량 계산 (활동량 × 배출계수)
→ 결과 저장
→ 대시보드 시각화
```

## 제한 시간

- 예상 작업량: 8~12시간
- 최대 기간: 3일

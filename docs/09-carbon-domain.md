# 탄소 회계 도메인 이해

> 이 문서는 과제 수행 및 발표 준비를 위한 도메인 이해 자료.
> 설계 결정의 근거로 활용할 것.

---

## 1. 왜 탄소 배출량을 측정하는가

기업이 탄소 배출량을 측정하는 이유는 크게 세 가지:

1. **규제 대응**: 탄소세, 배출권거래제(ETS), ESG 공시 의무화
2. **비용 관리**: 탄소 비용이 실질 재무 리스크로 편입되고 있음
3. **Net Zero 목표**: 2050 탄소중립 공약을 이행하기 위한 기준선 설정

HanaLoop의 대시보드는 경영진이 이 세 가지를 한 화면에서 파악할 수 있도록 돕는 도구.

---

## 2. GHG Protocol: Scope 1 / 2 / 3

국제적으로 가장 널리 쓰이는 탄소 회계 기준. 배출원을 세 범위(Scope)로 분류.

### Scope 1 — 직접 배출

기업이 직접 소유·운영하는 설비에서 나오는 배출.

| 예시      | 설명              |
| --------- | ----------------- |
| 경유 연소 | 자사 트럭, 보일러 |
| LNG 연소  | 자사 공장 열원    |
| 냉매 누출 | 에어컨, 냉장 설비 |

→ 기업이 가장 직접적으로 통제 가능.

### Scope 2 — 간접 배출 (구매 에너지)

외부에서 구매한 전기·열·증기를 사용할 때 발생하는 간접 배출.

| 예시          | 설명                  |
| ------------- | --------------------- |
| 한국전력 전기 | 전력 생산 과정의 배출 |
| 지역 난방     | 열 생산 과정의 배출   |

→ 에너지 효율 개선 또는 재생에너지 전환으로 감축 가능.

### Scope 3 — 가치사슬 전체 배출

공급망, 제품 사용, 폐기 등 Scope 1/2를 제외한 모든 간접 배출.

| 범주               | 예시                         |
| ------------------ | ---------------------------- |
| 구매한 상품/서비스 | 원자재 생산                  |
| 업스트림 운송      | 원료 운반 트럭               |
| 다운스트림 운송    | 제품 배달                    |
| 출장               | 항공, 기차                   |
| 직원 통근          | 자가용, 대중교통             |
| 판매 제품 사용     | 고객이 사용 중 발생하는 배출 |

→ 전체 기업 배출의 70~90%를 차지하는 경우가 많음. 감축이 가장 어려움.

```
Scope 1   [█████] 직접 통제
Scope 2   [███] 에너지 계약으로 통제
Scope 3   [████████████████████] 공급망 전체 — 가장 큰 비중
```

## 3. 활동 데이터 (Activity Data)

탄소 배출량을 계산하기 위한 원본 데이터. **얼마나 사용했는가**를 기록.

| 날짜    | 유형   | 설명           | 활동량 | 단위   |
| ------- | ------ | -------------- | ------ | ------ |
| 2025-01 | 전기   | 한국전력       | 110    | kWh    |
| 2025-01 | 원소재 | 플라스틱(HDPE) | 230    | kg     |
| 2025-01 | 운송   | 5톤 트럭       | 41     | ton-km |
| 2025-01 | 연료   | 경유           | 200    | L      |

**설계 원칙**: 활동 데이터는 원본 그대로 보존. 계산 결과와 분리해서 저장.
→ 배출계수가 개정되어도 활동 데이터를 바탕으로 **재계산** 가능.

---

## 4. 배출계수 (Emission Factor)

활동 데이터를 탄소 배출량으로 변환하는 계수.
**1단위 활동량당 발생하는 탄소 배출량 (kgCO2e/단위)**.

| 카테고리       | 배출계수 | 단위          | Scope | 출처             |
| -------------- | -------- | ------------- | ----- | ---------------- |
| 전기(한국)     | 0.4567   | kgCO2e/kWh    | 2     | 한국 환경부 2023 |
| 경유           | 2.68     | kgCO2e/L      | 1     | IPCC 2021        |
| LNG            | 2.20     | kgCO2e/kg     | 1     | IPCC 2021        |
| 플라스틱(HDPE) | 2.30     | kgCO2e/kg     | 3     | Ecoinvent 3.9    |
| 트럭(5톤)      | 0.092    | kgCO2e/ton-km | 3     | 국토부 2023      |
| 항공(국내)     | 0.255    | kgCO2e/km     | 3     | ICAO             |

**왜 버전 관리가 필요한가**:

- 배출계수는 에너지 믹스 변화에 따라 매년 개정됨 (특히 전기)
- 감사(Audit) 시 "이 배출량은 어떤 계수로 계산했는가"를 증명해야 함
- `valid_from` / `valid_to` 필드로 특정 시점의 계수를 재현 가능하게 관리

## 5. 탄소 배출량 계산 (PCF 계산)

```
배출량 (kgCO2e) = 활동량 × 배출계수
```

**예시**:

```
전기 110 kWh × 0.4567 kgCO2e/kWh = 50.24 kgCO2e
플라스틱 230 kg × 2.30 kgCO2e/kg = 529.00 kgCO2e
트럭 41 ton-km × 0.092 kgCO2e/ton-km = 3.77 kgCO2e
────────────────────────────────────────
합계                                  583.01 kgCO2e = 0.583 tCO2e
```

**단위 정리**:

- `kgCO2e`: 킬로그램 CO2 환산량 (입력·계산 단위)
- `tCO2e`: 톤 CO2 환산량 = kgCO2e ÷ 1000 (대시보드 표시 단위)
- `CO2e`: CO2 외 CH4, N2O 등 온실가스를 CO2 온난화 잠재력으로 환산한 값

## 6. 탄소세 (Carbon Tax)

배출량에 세율을 곱해 납부해야 할 비용.

```
탄소세 (원) = 배출량 (tCO2e) × 세율 (원/tCO2e)
```

| 국가/제도                 | 2024년 세율                  |
| ------------------------- | ---------------------------- |
| 한국 배출권거래제 (K-ETS) | 약 8,000~15,000원/tCO2e      |
| EU ETS                    | 약 60~70 EUR/tCO2e           |
| 스웨덴 탄소세             | 약 130 USD/tCO2e (세계 최고) |

→ 이 과제에서는 세율을 설정값으로 입력 가능하게 구조를 잡아두고, KPI 카드에서 "예상 탄소 비용"으로 표시 가능.

## 7. Net Zero란

**탄소 배출량 = 탄소 흡수량**이 되는 상태.

```
현재 배출량 → 감축 → 잔여 배출은 탄소 흡수/제거로 상쇄 → Net Zero
```

기업의 Net Zero 경로:

1. **기준선 측정**: 지금 얼마나 배출하는지 파악 (← 이 대시보드의 역할)
2. **목표 설정**: SBTi(과학 기반 목표) 기준으로 2030/2050 목표 수립
3. **감축 실행**: 에너지 효율, 재생에너지 전환, 공급망 개선
4. **잔여 상쇄**: 탄소 크레딧 구매, 조림 프로젝트

## 9. 발표 시 설명 포인트

- **왜 ActivityData와 EmissionResult를 분리했는가**:
  배출계수는 매년 바뀐다. 분리해두면 계수가 개정되어도 원본 활동 데이터로 재계산 가능. 감사 추적도 가능.

- **왜 배출계수에 validFrom/validTo를 뒀는가**:
  실제 탄소 관리 플랫폼의 필수 요건. "2024년 1월 배출량은 당시 유효했던 계수로 계산됐다"를 증명해야 함.

- **Scope 분류를 왜 자동으로 하는가**:
  활동 유형(전기=Scope2, 연료=Scope1, 운송=Scope3)에 따라 Scope가 결정된다. 사용자가 매번 Scope를 선택하면 입력 오류 위험이 높아지므로 자동화.

- **KPI 카드에 Scope별 배출량을 넣은 이유**:
  경영진은 총량보다 "어디서 줄일 수 있는가"를 더 궁금해한다. Scope1은 직접 통제 가능, Scope2는 재생에너지로 줄일 수 있고, Scope3은 공급망 개편이 필요 — 의사결정 방향이 다르다.

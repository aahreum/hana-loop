## 주요 결정 및 트레이드오프

### CarbonGauge — Recharts vs 순수 SVG

| 방향                           | 장점                                          | 단점                                             |
| ------------------------------ | --------------------------------------------- | ------------------------------------------------ |
| Recharts PieChart (50 segment) | Recharts 생태계 통일                          | 50개 path 요소, 그라디언트 적용 불가, DOM 무거움 |
| **순수 SVG 단일 arc path** ✅  | DOM 요소 1개, CSS gradient 자유롭게 적용 가능 | SVG arc 수식 직접 구현 필요                      |

→ **순수 SVG 선택.** `M LX CY A R R 0 0 1 nx ny` — sweep=1 (clockwise in SVG y-down = 위를 통과).
`gradientUnits="userSpaceOnUse"`로 x1=LX, x2=RX 고정해 채움량과 무관하게 그라디언트 일정.

### categoryBarData 월 초기화 기준

| 방향                                         | 문제                                                     |
| -------------------------------------------- | -------------------------------------------------------- |
| `activities` 전체로 월 초기화 (기존)         | 기간 필터 밖의 월이 차트에 포함 → trendData와 x축 불일치 |
| **`results`(기간 필터 적용)로 월 초기화** ✅ | 모든 차트 x축 일치                                       |

### 공유 상수 위치

TYPE_LABELS, SCOPE_BADGE가 4개 파일에 중복 → `shared/constants/activityLabels.ts`로 추출.

| 오류                                     | 원인                                                       | 수정                                           |

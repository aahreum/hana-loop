## 라이트하우스 81점 미통과 항목 — 해결 매핑

### 이름 및 라벨

| 요소                                          | 처리                                                |
| --------------------------------------------- | --------------------------------------------------- |
| NavigationDrawer 모바일 X 버튼                | `aria-label="사이드바 닫기"`                        |
| Header 햄버거 메뉴 버튼                       | `aria-label="사이드바 열기"`                        |
| 회사 선택 `<select>`                          | `<label htmlFor>` (`id="company-select"`)           |
| 날짜 `<input type="month">` × 2               | `<label htmlFor>` (sr-only) + `aria-label`          |

### 색 대비 (WCAG AA 4.5:1)

| 영역                                | 변경                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| 탄소 등급 게이지 5색 (`gaugeZones`) | violet/blue/sky/yellow/green darker 톤 → white text 5:1 이상                   |
| 활동 유형 뱃지 (`bg-primary-bg`)    | `text-primary` → `text-primary-pressed` (3.4:1 → 7.5:1)                       |
| Scope 뱃지 (`bg-scope*/10`)         | 새 시맨틱 토큰 `--scope*-text`, 라이트=`*-700` / 다크=`*-300`로 분기            |

### `[aria-hidden]` + 포커스 가능 자식 경고

| 문제                                                                                              | 처리                                                                                                                          |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `<aside aria-hidden="true">` 안에 button/select/`<a>` 등 포커스 가능 요소 있어 보조기술 사용자에 혼란 | `aria-hidden` 제거 → `inert` 속성으로 교체. `useEffect + matchMedia('(min-width: 1024px)')`로 데스크탑/모바일 분기, 실제 안 보일 때만 적용 |

### 추가 a11y 보강

- `<aside aria-label="주 탐색">`, `<nav aria-label="페이지 탐색">`
- 활성 메뉴 `aria-current="page"`
- 장식 아이콘 (Icon, ChevronLeft, ~/구분자) `aria-hidden`
- 모바일 드로어 오버레이 `aria-hidden`

## 주요 결정 및 트레이드오프

### 사이드바 접힘 표현 — width 0 vs icon-only collapsed

| 방향                         | 장점                              | 단점                                  |
| ---------------------------- | --------------------------------- | ------------------------------------- |
| **width 0 (`lg:hidden`)** ✅ | 단순, 본문 영역 최대 활용         | 접혔을 때 메뉴 접근에 클릭 한 번 더    |
| icon-only (~56px)            | 메뉴 즉시 식별                    | 디자인 토큰/테스트 추가 필요          |

→ 우선 width 0으로 단순 적용. 사용자 피드백 후 icon-only 검토.

### 비표시 자식 포커스 차단 — `aria-hidden` vs `inert`

| 방향                                                | 장점                                                                | 단점                                            |
| --------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------- |
| `aria-hidden="true"` (이전)                         | 단순                                                                | 자식 포커스 차단되지 않음 → Lighthouse 경고     |
| **`inert` 속성** ✅                                 | 자식 포커스/이벤트 모두 차단, 접근성 트리에서도 제외                 | 뷰포트 분기 위해 `useEffect + matchMedia` 필요   |

→ React 19 `inert` 부울 prop 지원. matchMedia로 데스크탑(`desktopCollapsed`) / 모바일(`!open`) 분기.

### Scope 텍스트 토큰 분리

| 방향                                  | 장점                                              | 단점                                  |
| ------------------------------------- | ------------------------------------------------- | ------------------------------------- |
| `--scope1/2/3` 단일 토큰              | 토큰 수 적음                                      | 차트 fill 전용 색은 텍스트 대비 부족  |
| **`--scope*-text` 별도 토큰** ✅      | 차트는 GHG 컨벤션 유지, 텍스트는 AA 충족          | 토큰 한 쌍 추가                       |

→ CLAUDE.md "Scope 색상 절대 변경 금지" 준수하면서 a11y 충족.

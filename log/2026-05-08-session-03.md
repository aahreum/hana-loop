2. **날짜 placeholder 버그 — "2025-01 ~ 2025-08 고정 표시"**
   → 회사 미선택 시 고정 날짜가 그대로 보이는 문제. `value={noCompany ? '' : from}` + `disabled` 처리로 1차 수정 → UI 깨짐 발생. 2차로 `noCompany`일 때 `<span>YYYY.MM</span>`으로 교체하는 방식으로 확정.

3. **cursor-pointer 규칙 추가 + 전수조사**
   → `.claude/rules/react-coding-conventions.md`에 규칙 추가. `NavigationDrawer` 로고/X버튼/nav Links, `DashboardContainer` "전체 보기" 링크 수정.

   → 처음에 외부 링크 예외 추가했다가 "예외 넣지 말라"는 피드백으로 제거. Next.js `<Link>`는 외부 URL도 지원. `DashboardContainer`의 `<a href="/activities">` → `<Link>` 교체.

5. **cursor-pointer 누락 추가 수정**
   → "활동 추가" Button과 날짜 input 두 개 누락 발견. 각각 `cursor-pointer` 추가.

6. **CSS import TS 오류 (`'./globals.css'` 모듈 선언 없음)**
   → `src/types/global.d.ts`에 `declare module '*.css'` 추가.

## 주요 결정 및 트레이드오프

### 날짜 placeholder 방식

| 방향                                    | 장점                               | 단점                             |
| --------------------------------------- | ---------------------------------- | -------------------------------- |
| `value=""` + `disabled`                 | 구현 단순                          | `disabled` 스타일로 UI 크기 달라짐 |
| **`noCompany`일 때 `<span>`으로 교체** ✅ | 완전히 동일한 시각적 크기·스타일   | 조건부 렌더링 분기 필요          |

→ UI 일관성이 중요하므로 span 교체 방식 채택.

### `<a>` 예외 처리 없이 Link만 사용

| 방향                            | 장점                       | 단점              |
| ------------------------------- | -------------------------- | ----------------- |
| 외부 URL은 `<a>` 예외 허용      | 친숙한 패턴                | 규칙 예외 필요    |
| **`<Link>`로 통일** ✅           | 규칙 단순, 예외 없음       | -                 |

→ Next.js `<Link>`가 외부 URL도 지원하므로 예외 불필요.

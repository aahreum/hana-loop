## 주요 결정 및 트레이드오프

### 정보 구조 — Scope 중심 vs 활동 원인 중심

| 방향                                    | 장점                                                | 단점                                          |
| --------------------------------------- | --------------------------------------------------- | --------------------------------------------- |
| Scope 1/2/3 그대로 유지                 | GHG Protocol 표준 부합                              | 비전문가가 즉시 해석 어려움                   |
| **활동 유형(전기/원자재/운송) 중심** ✅ | 일상 어휘로 직관적 이해 가능                        | Scope 분류는 보조 표기로 잔존                 |

### 월별 추이 그래프 — A안(단일 라인) vs B안(stacked area)

| 방향                                  | 장점                                  | 단점                                       |
| ------------------------------------- | ------------------------------------- | ------------------------------------------ |
| A안: 총 배출량 단일 라인              | 가장 단순                             | "어떤 활동이 원인인지" 보이지 않음         |
| **B안: 활동 유형별 stacked area** ✅  | 전체 추이 + 원인 구성 동시            | 시각적 부담 약간 증가                      |

### 인사이트 메시지 — 룰 함수 ReactNode vs 평문 + UI 파싱

| 방향                                | 장점                                       | 단점                                       |
| ----------------------------------- | ------------------------------------------ | ------------------------------------------ |
| 룰 함수가 ReactNode 반환            | 강조 구간 명시적                           | 데이터 레이어가 JSX에 결합, 테스트 부담    |
| **평문 + InsightList에서 정규식** ✅ | 룰 함수는 순수 string, 결합 없음           | 강조 판정이 정규식 휴리스틱(\d+%[↓↑]?)     |

→ B 채택. Insight 타입은 `{ message: string; tone }` 유지, 렌더 시점 강조.

### 계산식 안내 — 인라인 메시지 vs 도움말 툴팁

| 방향                          | 장점                              | 단점                          |
| ----------------------------- | --------------------------------- | ----------------------------- |
| 인사이트 리스트 항목 추가     | 항상 보여서 발견 쉬움             | 시각 노이즈, "분석"이 아님    |
| **도움말 ? 툴팁(UnitTooltip)** ✅ | 깔끔, "계산식이란?" 패턴 일관성   | 처음엔 클릭해야 알 수 있음    |

→ B 채택. 도넛 카드 헤더 우측에 `[계산식 ?]` 표시.

### 페이지 스크롤 — 내부 영역 vs 브라우저 자체

| 방향                  | 장점                              | 단점                                     |
| --------------------- | --------------------------------- | ---------------------------------------- |
| 내부 main `overflow-y-auto` | sticky 상단 고정 자동              | 모바일 UX 부자연, 콘텐츠와 스크롤 분리감 |
| **브라우저 native** ✅ | 모바일 자연스럽고 일관됨           | sidebar/header sticky 별도 처리 필요     |

→ AppShell `min-h-screen`, sidebar `lg:sticky h-screen`, Header `sticky top-0` 으로 양쪽 사용성 충족.

### 헤딩 계층

| 태그 | 적용                                  | 크기            |
| ---- | ------------------------------------- | --------------- |
| h1   | 로고 (HanaLoop)                       | text-base       |
| h2   | 페이지 타이틀                         | text-lg / muted |
| h3   | 섹션 라벨, 페이지 내부 카드 타이틀    | text-base       |
| h4   | 대시보드 카드 헤더 (CardSectionHeader)| text-lg / 흰색  |

→ 시각 우선순위는 h4가 h2/h3보다 큼 (콘텐츠 우선). 시맨틱 계층은 보존.

## 자동 인사이트 룰 (`shared/lib/insights.ts`)

| 함수                       | 출력 위치                | 룰 요약                                                                        |
| -------------------------- | ------------------------ | ------------------------------------------------------------------------------ |
| `interpretChangeRate`      | KPI 전월 대비             | abs<0.5%=neutral, <0%=good, >0%=warn                                           |
| `interpretTopCategory`     | KPI 최대 배출원          | share≥0.5=warn(대부분), 그 외=neutral                                          |
| `interpretPeakMonth`       | KPI 최대 배출 시점       | "X월"                                                                          |
| `buildDonutInsights`       | 도넛 요약                | share≥0.5/0.35/그 외 3단계 — 비전문가용 메시지                                 |
| `buildTrendInsights`       | 추이 자동 분석 (최대 3)  | 룰1: 최대 증가(+5%↑), 룰2: 안정(±5% 내), 룰3: 감소(-5%↓)                       |
| `buildGradeInsights`       | 등급 사유 + 업계 비교    | totalChangeRate + topCategory.share + score 휴리스틱                           |
| `buildReductionSuggestions` | 감축 제안 (최대 3)       | 활동별 절감률 — 전기 10%/운송 18%/원자재 8%/연료 12%/폐기물 15%, 연간 환산 |

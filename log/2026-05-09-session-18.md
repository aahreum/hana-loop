### 2. forwardRef — 룰 예외 처리

| 방향                                  | 장점                              | 단점                                            |
| ------------------------------------- | --------------------------------- | ----------------------------------------------- |
| 모든 컴포넌트 forwardRef 제거 (React 19) | 룰 일관성                          | shadcn 원본 다수 수정 → "shadcn 수정 금지" 룰 위반 |
| **shadcn 원본 패턴 유지** ✅           | shadcn 룰 우선 적용. 동일 카테고리 일관 | React 19 룰의 부분 예외                         |

→ shadcn 컴포넌트(dialog, popover, scroll-area, card, tooltip, label, select 등) 는 모두 forwardRef. 호환성과 일관성 위해 wrapper(`AppDialogContent`) 도 동일 패턴.

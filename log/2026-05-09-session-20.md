## 주요 결정 및 트레이드오프

### 모바일 native input dropdown chevron 처리

| 방향                                            | 장점                              | 단점                                            |
| ----------------------------------------------- | --------------------------------- | ----------------------------------------------- |
| `display: none` 으로 picker indicator 차단     | 중첩 자체 제거                     | picker 트리거가 막혀 input 클릭 시 picker 열리지 않음 — 사용 불가 |
| `pr-{n}` 패딩 키우기                           | 변경 폭 최소                      | Samsung 의 별도 chevron 은 native chrome 이라 padding 으로 못 가림 |
| **`-webkit-appearance: none; appearance: none;`** ✅ | native chrome 통째 제거. picker 동작은 유지 (input 클릭 시 그대로 열림) | webkit 외 일부 브라우저에서 동작 차이 가능성 (현재 chromium-only 영향이라 영향 없음) |

→ 근본 원인이 Samsung Internet 의 별도 dropdown chevron 이라 picker indicator 만 숨기는 기존 처리(`opacity:0`)로는 못 가린다. `appearance: none` 으로 native chrome 자체를 제거하면 picker 동작은 그대로 유지된 채 시각만 깔끔해진다.

## 주요 결정 및 트레이드오프

### 1. 사이드바 라인 톤 — `--sidebar-border` 토큰 vs alpha 약화

| 방향                              | 장점                                | 단점                                            |
| --------------------------------- | ----------------------------------- | ----------------------------------------------- |
| 별도 `--sidebar-border` 토큰 정의  | 명시적 시맨틱                       | 토큰 1개 추가, 사이드바 안에서만 쓰여 비례 ↑    |
| **`border-white/10` → `border-white/5`** ✅ | 한 줄 변경, 사이드바 다크 navy 위에서 자연스러운 약화 | 토큰화 안 됨 — 다음에 같은 패턴 나올 시 중복 위험 |

→ 이번엔 단일 컴포넌트라 alpha 약화로 충분. 사이드바 외에서 같은 상황이 또 나오면 그때 토큰화.

### 2. 바텀시트 배경 — `bg-surface` 명시 vs shadcn 기본값 변경

| 방향                                  | 장점                              | 단점                                                |
| ------------------------------------- | --------------------------------- | --------------------------------------------------- |
| shadcn `dialog.tsx` 의 `bg-background` 자체를 `bg-surface` 로 변경 | 한 번에 전체 다이얼로그 통일 | shadcn 원본 수정 — CLAUDE.md "shadcn 수정 금지" 위반 |
| **호출부(`ActivityFormDialog`) 에 `bg-surface` 명시** ✅ | shadcn 원본 보존, props 로만 커스터마이징 | 새 다이얼로그 추가 시 명시 필요 (docs/05 에 규칙 명시) |

→ shadcn 컴포넌트 수정 금지 룰 준수. 디자인 시스템 docs 에 "모든 다이얼로그에 `bg-surface` 명시" 규칙 추가.

### 3. 모바일 가로 스크롤 — `overflow-x: clip` vs `hidden`

| 방향               | 장점                              | 단점                                            |
| ------------------ | --------------------------------- | ----------------------------------------------- |
| `overflow-x: hidden` | 호환성 ↑                         | stacking context 생성 → `position: sticky` 가 부모(body) 안에서 의도와 다르게 동작할 수 있음 |
| **`overflow-x: clip`** ✅ | sticky 동작 보존, 같은 차단 효과 | IE 등 구형 브라우저 미지원 (Next.js 15 환경에선 문제 없음) |

→ `clip` 표준 처방. NavigationDrawer 의 `lg:sticky` 와 Header 의 `sticky top-0` 가 둘 다 보존됨.

### 4. NavigationDrawer 모바일 닫힘 처리 — `display: none` vs `translate`

`-translate-x-full` 유지 + `body { overflow-x: clip }` 으로 누설 차단을 선택.

| 방향               | 장점                              | 단점                                            |
| ------------------ | --------------------------------- | ----------------------------------------------- |
| `display: none` 으로 닫힘 | overflow 누설 자체가 없음        | open/close 슬라이드 애니메이션 사라짐, drawer UX 핵심 손실 |
| **translate 유지 + body overflow-x: clip** ✅ | 슬라이드 애니메이션 보존         | body 에 한 줄 추가                              |

→ 드로어 UX 보존이 우선. clip 으로 누설만 차단.
